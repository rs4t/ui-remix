# Inspiration references (who to study for what)

User-supplied mapping of category to the product/studio that sets the bar. Use it as a *taste anchor*: when a brief touches the category, open that product (or search its screens/design system) and extract decisions about hierarchy, density, spacing, type and motion. Never copy brand, copy or exact layouts. Data-driven alternatives: `reference/styles/styles.md` section F (GradientDeck design.md library) and `python scripts/search.py "<q>" --domain style`.

| Category | Reference | What to study | Go deeper in this skill |
|---|---|---|---|
| Animation | Apple | Spring physics, interruptibility, velocity handoff, materials, restraint | `reference/motion/motion.md` sections 5-7, `apple-principles.md` |
| Onboarding | Duolingo | Progressive disclosure, tiny wins, character and delight at rare moments, clear single action per step | `reference/motion/motion.md` (delight tier), `reference/patterns/ui-craft/state-design.md`, `reference/ux-rules/ux-laws.md` (Hick, Peak-end) |
| UI design | Linear | Density, speed, keyboard-first, restrained color, no animation on high-frequency actions | `reference/motion/motion.md` section 3, `reference/styles/styles.md` A, `reference/ui-polish/ui-polish.md` |
| Typography | Pentagram | Type as identity, scale contrast, considered pairing, editorial grids | `reference/typography/typography.md`, `reference/brand/brand.md` |
| Minimalism | Muji | Reduction to essentials, material honesty, quiet neutrals, generous space | `reference/styles/styles.md` A, `reference/layout/layout.md` |
| Art direction | Aesop | Cohesive world: restrained palette, tactile photography, serif/sans pairing with intent, copy voice | `reference/brand/brandkit.md`, `reference/taste-anti-slop/taste.md` section 0.2 |
| Dashboards | Notion | Document-like calm, flat surfaces, subtle pastels, progressive disclosure, empty states that teach | `reference/styles/styles.md` A, `reference/ui-polish/interface-design.md`, `reference/patterns/ui-craft/dashboard.md` |
