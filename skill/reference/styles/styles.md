# Style directions (canonical)

Merged from: minimalist-ui, high-end-visual-design, industrial-brutalist-ui, gpt-taste, stitch-design-taste (SKILL + DESIGN.md), gradientdeck. Each is a named aesthetic direction you can choose when the brief fits. The universal anti-slop rules they all repeat (no emoji, no pure black, no Inter-by-default, no 3 equal cards, no neon glow, no `h-screen`, no fake numbers/names/clichés, transform/opacity only, picsum placeholders, `min-h-[100dvh]`, mobile collapse under 768px, left-aligned/asymmetric heroes at high variance) live ONCE in `reference/taste-anti-slop/taste.md`. Do not restate them here. More data-driven style picking: `python scripts/search.py "<query>" --domain style`.

How to choose: run taste.md section 0 (read the room, Design Read, dials) first, then pick ONE direction below (never mix two on one page, a rule several sources state independently). Dial vocabulary is identical across sources (Stitch's Creativity/Density/Variance/Motion = taste.md's dials; defaults 8/6/4).

---

## A. Minimalist editorial ("premium utilitarian minimalism")
For Notion/Linear-like document-style products, calm SaaS, workspaces. Warm monochrome, typographic contrast, flat bento, muted pastels. No gradients, no heavy shadows.
- Banned: Inter/Roboto/Open Sans; thin-line icon sets (Lucide, Feather, Heroicons); `shadow-md/lg/xl` (shadows near zero or ultra-diffuse under 0.05 opacity); primary-colored big surfaces; gradients, neon, 3D glass (subtle navbar blur only); `rounded-full` on large containers/cards/primary buttons.
- Type: sans `'SF Pro Display','Geist Sans','Helvetica Neue','Switzer'`; serif for hero headings and quotes `'Lyon Text','Newsreader','Playfair Display','Instrument Serif'` with tracking -0.02 to -0.04em and line-height 1.1; mono `'Geist Mono','SF Mono','JetBrains Mono'`. Body never `#000`: `#111111` or `#2F3437`, line-height 1.6; secondary `#787774`.
- Color: canvas `#FFFFFF` / `#F7F6F3` / `#FBFBFA`; card `#FFFFFF` / `#F9F9F8`; border `#EAEAEA` or `rgba(0,0,0,.06)`. Pastel pairs (bg / text): red `#FDEBEC`/`#9F2F2D`, blue `#E1F3FE`/`#1F6C9F`, green `#EDF3EC`/`#346538`, yellow `#FBF3DB`/`#956400`; pastels only for tags, inline code, icon backgrounds.
- Components: asymmetric bento, cards exactly `1px solid #EAEAEA`, radius 8-12px max, padding 24-40px. Primary button `#111` on `#fff`, radius 4-6px, no shadow, hover `#333` or `scale(.98)`. Tags pill (9999px), `text-xs`, uppercase, tracking .05em, pastel bg. FAQ accordions with no boxes (only `border-bottom`), `+`/`-` toggles. Shortcuts as `<kbd>` (1px `#EAEAEA`, radius 4, bg `#F7F6F3`, mono). Mockups in minimal faux-OS chrome (white bar, three light-gray dots).
- Icons: Phosphor (Bold/Fill) or Radix, one stroke width. Illustrations: monochrome rough continuous-line ink sketches + one offset pastel geometric shape. Photos desaturated and warm with `opacity .04` warm grain. Backgrounds never flat: low-opacity full-width imagery, radial warm light spots at opacity .03, or minimal line patterns.
- Motion: scroll entry `translateY(12px)`+opacity over 600ms `cubic-bezier(.16,1,.3,1)` via IntersectionObserver; hover shadow `0 0 0` to `0 2px 8px rgba(0,0,0,.04)` over 200ms; stagger `calc(var(--index)*80ms)`; optional single slow ambient radial blob (20s+, opacity .02-.04) on a fixed pointer-events-none layer.
- Execution order: macro whitespace first (`py-24`/`py-32`), constrain type to `max-w-4xl/5xl`, apply the type and mono-color variables, enforce the `1px #EAEAEA` rule, add scroll entries, ensure depth in every section.

## B. High-end agency ("$150k build", Apple/Linear-tier)
Variance mandate: never produce the same layout twice in a row; pick one vibe + one layout archetype.
- Absolute-zero list (adds to taste.md): banned fonts Inter, Roboto, Arial, Open Sans, Helvetica (use Geist, Clash Display, PP Editorial New, Plus Jakarta Sans); thick-stroked Lucide/FontAwesome/Material icons (use ultra-light Phosphor Light or Remix Line); generic 1px solid gray borders; harsh shadows (`shadow-md`, `rgba(0,0,0,.3)`); edge-to-edge sticky navbars; symmetrical 3-column Bootstrap grids without big whitespace; `linear` or `ease-in-out`; instant state changes.
- Vibe archetypes (pick 1): **Ethereal Glass** (SaaS/AI): OLED black `#050505`, radial mesh orbs, vantablack cards with `backdrop-blur-2xl` and white/10 hairlines, wide geometric grotesk. **Editorial Luxury** (lifestyle/real estate/agency): warm cream `#FDFBF7`, sage or espresso, high-contrast variable serif display, film-grain overlay `opacity-[0.03]`. **Soft Structuralism** (consumer/health/portfolio): silver-grey or white, massive bold grotesk, floating components with very soft diffused shadows. (Palette warning: taste.md bans defaulting to cream/espresso for premium-consumer; use only if the brief fits.)
- Layout archetypes (pick 1), each with mobile collapse: **Asymmetrical Bento** (`col-span-8 row-span-2` beside stacked `col-span-4`; mobile `grid-cols-1 gap-6`), **Z-Axis Cascade** (overlapping cards with -2deg/3deg rotation; remove rotations and negative-margin overlaps below 768px), **Editorial Split** (huge type left `w-1/2`, scrollable pills/cards right; mobile `w-full` stack).
- Double-Bezel (Doppelrand): never place a premium card flat. Outer shell `bg-black/5` or `bg-white/5`, hairline `ring-1 ring-black/5` or `border border-white/10`, padding `p-1.5`/`p-2`, radius `rounded-[2rem]`; inner core with its own bg, inset highlight `shadow-[inset_0_1px_1px_rgba(255,255,255,.15)]`, concentric radius `calc(2rem - .375rem)`.
- Button-in-Button: primary CTAs are `rounded-full` pills (`px-6 py-3`); a trailing arrow sits in its own circular wrapper (`w-8 h-8 rounded-full bg-black/5 dark:bg-white/10`) flush with the inner right padding; on hover the wrapper translates `translate-x-1 -translate-y-[1px]` and scales 1.05; press `active:scale-[.98]`.
- Spatial rhythm: section padding `py-24` to `py-40`. Eyebrow pill (`rounded-full px-3 py-1 text-[10px] uppercase tracking-[.2em]`) is allowed here, but taste.md's eyebrow cap (1 per 3 sections) still applies.
- Motion: all transitions use `cubic-bezier(.32,.72,0,1)` at ~700ms; Fluid Island nav = floating glass pill (`mt-6 mx-auto w-max rounded-full`); hamburger lines rotate/translate into a true X; menu opens as a full-screen overlay (`backdrop-blur-3xl bg-black/80` or `bg-white/80`) with links sliding up from `translate-y-12` with 100/150/200ms stagger; scroll entry `translate-y-16 blur-md opacity-0` to resolved over 800ms+ via IntersectionObserver or `whileInView`.
- Guardrails: `backdrop-blur` only on fixed/sticky elements, never scrolling containers; grain on fixed pointer-events-none pseudo-elements; z-index only for systemic layers.
- Protocol: silent roll of vibe + layout, scaffold background/whitespace/type, architect with double-bezel and squircle radii, choreograph, output. Checklist: no banned items, archetypes chosen, double-bezel on major cards, button-in-button where applicable, `py-24` minimum, custom beziers only, scroll entries present, collapse under 768px, transform/opacity only, blur only on fixed elements.

## C. Industrial brutalist / Swiss print / tactical telemetry
For data-heavy dashboards, portfolios, editorial that should feel like declassified blueprints. Pick ONE mode and never mix.
- Modes: **Swiss Industrial Print** (light, newsprint, heavy sans, visible dividing lines, oversized viewport-bleeding numerals, red accent) or **Tactical Telemetry / CRT** (dark only, dense tabular mono, ASCII brackets, crosshairs, phosphor glow, scanlines, low bit-depth).
- Type: macro headers neo-grotesque heavy (Neue Haas Grotesk Black, Archivo Black, Roboto Flex Heavy, Monument Extended; Inter ExtraBold is allowed here only as a heavy header), `clamp(4rem,10vw,15rem)`, tracking -0.03 to -0.06em, leading .85-.95, all caps. Micro text mono (JetBrains Mono, IBM Plex Mono, Space Mono, VT323, Courier Prime), 10-14px, tracking .05-.1em, leading 1.2-1.4, all caps, for metadata/nav/IDs/coordinates. High-contrast serif (Playfair, EB Garamond) used rarely and degraded with halftone/1-bit dithering.
- Color: no gradients, soft shadows or translucency. Light: bg `#F4F4F0`/`#EAE8E3`, ink `#050505`-`#111`, accent `#E61919`/`#FF2A2A` (the ONLY accent: strike-throughs, structural lines, vital data). Dark: bg `#0A0A0A`/`#121212` (no pure black), fg `#EAEAEA`, same red; terminal green `#4AF626` optional, only one status/readout element.
- Layout: strict CSS Grid anchored to tracks; visible compartmentalization with 1-2px solid borders and full-width `<hr>`; bimodal density (packed mono metadata vs vast negative space around macro type); zero border-radius.
- Components: ASCII framing `[ DELIVERY SYSTEMS ]`, `< RE-IND >`, `>>>`, `///`; registration/copyright/trademark marks as structural geometry; crosshairs at grid intersections, barcodes, warning stripes, fake rev/unit strings.
- Effects: halftone via `mix-blend-mode: multiply` + SVG dot patterns; CRT `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,.1) 2px, rgba(0,0,0,.1) 4px)`; global low-opacity SVG noise.
- Engineering: `display:grid; gap:1px` with contrasting parent/child backgrounds for razor-thin dividers; semantic tags (`<data>`, `<samp>`, `<kbd>`, `<output>`, `<dl>`); `clamp()` only for macro type.
- Note: taste.md bans uppercase tracked eyebrow spam and unmotivated mono labels for generic sites; here uppercase mono is the style's core vocabulary, so it is allowed when this direction is chosen deliberately.

## D. Awwwards GSAP engineer (gpt-taste)
For maximalist, motion-rich marketing sites. Beyond the stack rules in taste.md/recipes.md:
- Variation discipline: before coding, simulate a deterministic seeded random choice (e.g. prompt character count modulo) of 1 hero architecture, 1 type stack (Satoshi, Cabinet Grotesk, Outfit or Geist; never Inter), 3 component architectures, 2 GSAP paradigms, and do not default to the same UI twice. Output a `<design_plan>` first: RNG result, AIDA check, hero math (the `max-w` on the H1), bento density proof, label sweep and button check.
- Page structure AIDA: creative nav (floating glass pill or minimal split) then Attention (cinematic hero), Interest (dense gapless bento or typographic components), Desire (GSAP pinned/horizontal/text reveals), Action (huge high-contrast CTA + footer). Huge vertical padding (`py-32 md:py-48`) so sections read as chapters.
- Hero 2-line iron rule: H1 never exceeds 2-3 lines; ultra-wide container (`max-w-5xl/6xl/w-full`), `clamp(3rem,5vw,5.5rem)`. Hero options: Cinematic Center (preferred by this source; note taste.md avoids centered hero at variance above 4, so use only for launch/manifesto/cinematic briefs), Artistic Asymmetry (offset text with a floating image overlapping from bottom right), Editorial Split with huge negative space. Exactly two high-contrast CTAs; no floating stamp icons, pill tags under the hero, or raw stats in the hero (conflicts with taste.md's "max 1 primary + 1 secondary": same thing). Full-bleed background image with a dark radial wash.
- Gapless bento: `grid-flow-dense` always, prove `col-span`/`row-span` interlock, 3-5 intentional cards beats 8 messy ones, fill with imagery, dense type or CSS effects.
- GSAP paradigms: hover physics (`group-hover:scale-105 transition-transform duration-700 ease-out` in `overflow-hidden`); scroll-pinned split (title pinned left while a gallery scrolls on the right); image scale and fade (start `scale .8`, grow to 1 entering, darken to `opacity .2` leaving); scrubbing word-by-word text reveal (opacity .1 to 1); card stacking from the bottom.
- Component arsenal: inline typography images (small pill images inside the headline: `inline-block w-24 h-10 rounded-full align-middle bg-cover mx-2`), horizontal accordions (vertical slices expand horizontally on hover), single infinite marquee of Phosphor icons or large type, testimonial carousel with overlapping portraits and minimalist quotes.
- Content: no "SECTION 01"/"QUESTION 05" meta-labels; picsum images with CSS filters (`grayscale`, `mix-blend-luminosity`, `opacity-90`, `contrast-125`); deep radial blurs and grainy mesh backgrounds; wrap the page in `<main className="overflow-x-hidden w-full max-w-full">` to stop horizontal scrollbars from off-screen animation. No emojis. Button text contrast always legible.

## E. Stitch DESIGN.md generator (Google Stitch)
Use when producing a `DESIGN.md` that tells Stitch (or any agent) how to render a taste-compliant UI. Stitch interprets "visual descriptions" backed by precise values; translate jargon into words ("generously rounded corners (2.5rem)").
- Dials (Creativity 8, Density 4, Variance 8, Motion 6 defaults): Creativity 1-3 = quiet Notion-like; 7-10 = inline image typography, dramatic scale, strong asymmetry.
- Palette base: Canvas `#F9FAFB`, Surface `#FFFFFF`, Ink `#18181B`, Secondary `#71717A`, Tertiary `#94A3B8`, Border `rgba(226,232,240,.5)`, diffused shadow `0 20px 40px -15px rgba(0,0,0,.05)`. Accent (pick ONE): Emerald `#10B981` growth/success, Electric Blue `#3B82F6` productivity/dev tools, Deep Rose `#E11D48` creative/editorial, Amber `#F59E0B` community/social.
- Type: display Geist/Satoshi/Cabinet Grotesk/Outfit, tracking -0.025em, weight 700-900, leading 1.1, `clamp(2.25rem,5vw,3.75rem)`; body weight 400, leading 1.65, 65ch, `#71717A`; mono Geist Mono/JetBrains Mono (all numbers mono above density 7). Stitch's serif rule differs from taste.md: it bans Times/Georgia/Garamond/Palatino and allows Fraunces, Gambarino, Editorial New, Instrument Serif; taste.md bans Fraunces/Instrument Serif as defaults. Resolution: follow taste.md's serif discipline.
- Components: cards 2.5rem radius, padding 2-2.5rem; inputs label above, error below in Deep Rose, focus ring 2px offset in accent, no floating labels; nav sleek sticky, icons scale on hover, no desktop hamburger; skeleton shimmer matching layout and radii; empty states are composed illustrations with guidance; errors inline with a recovery action.
- Hero (Stitch rules): inline-image typography ("We build [photo] digital [photo] products", images at type-height, rounded), no overlapping elements anywhere (no absolute layering of content on content, no z-index stacking of content), no filler text (scroll to explore, swipe down, chevrons), asymmetric structure, max one primary CTA and no secondary "Learn more".
- Responsive (hard requirement; test at 375, 390, 768, 1024, 1440): single-column collapse under 768 (`width:100%`, `padding:1rem`, `gap:1.5rem`), no horizontal scroll, `clamp()` headlines, body at least 1rem (never below 14px), 44px tap targets, full-width mobile buttons, inline-image headlines stack below on mobile, nav collapses to labeled menu, section gaps `clamp(3rem,8vw,6rem)`.
- Motion intent documented for the coding phase (Stitch is static): spring `stiffness:100, damping:20`, perpetual micro-loops only on live components, stagger `calc(var(--index)*100ms)`, shared-element reordering, transform/opacity only, heavy loops isolated.
- DESIGN.md skeleton: 1 Visual Theme and Atmosphere; 2 Color Palette and Roles (name + hex + role, max 1 accent); 3 Typography Rules; 4 Component Stylings; 5 Layout Principles; 6 Motion and Interaction; 7 Anti-Patterns (banned list). Best practice: descriptive + functional + consistent + precise + opinionated; name colors by purpose; encode the bans; start from atmosphere.

## F. Reference library lookup (GradientDeck)
1,270 real-site `DESIGN.md` files (colors, type, spacing, components, surfaces, imagery, layout, do/don't). No account or key. Use as reference, never to pass off another brand.
- Index JSON (~1MB: slug, name, nickname, industry, theme, colors, fonts): `https://ui.gradientdeck.com/library.json`; nicknames: `https://ui.gradientdeck.com/llms.txt`; compact design (~3k tokens): `https://ui.gradientdeck.com/styles/{slug}/design.md`; extended with token tables and agent prompt guide (~5k tokens): `.../design-extended.md`.
- Procedure: never read library.json whole (filter with a script on `industry`, `theme`, `nickname`, `name`, or grep llms.txt), pick 2-3 candidates, fetch their `design.md`, compare, save the chosen one as `DESIGN.md` in the project and follow it for every color/font/spacing/component. Take structure and rules, not the brand; keep the product's own name, copy and content.

## G. Conflicts resolved
| Topic | Disagreement | Resolution |
|---|---|---|
| Inter | banned absolutely (high-end, minimalist, gpt-taste, stitch) vs allowed as heavy header (brutalist) vs discouraged-with-overrides (taste.md) | taste.md rule; brutalist heavy-header use allowed inside that style |
| Serif | minimalist/high-end embrace serif; stitch/taste ban generic or LLM-favorite serifs | taste.md serif discipline governs; named Instrument Serif/Fraunces in A and E are defaults to avoid |
| Centered hero | gpt-taste "cinematic center highly preferred" vs taste/stitch ban at variance above 4 | Centered only for manifesto/launch/cinematic briefs |
| Eyebrow tags | high-end requires them | taste.md eyebrow cap applies |
| Icons | minimalist bans Lucide/Feather/Heroicons; high-end bans thick Lucide; taste allows Lucide only if project uses it | Prefer Phosphor (Light/Bold/Fill) or Radix in these styles |
| Easing | high-end bans `ease-in-out`/`linear`; motion.md allows ease-in-out for on-screen movement | Use custom beziers in B; motion.md tokens otherwise |
| Shadows | minimalist near-zero; Stitch diffused 40px; brutalist none | Per chosen style |
| Perpetual loops | Stitch "every active component loops" | Only genuinely live components (motion.md section 14) |
